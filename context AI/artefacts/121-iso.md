# Le parallèle, chaque fiche dans son worktree — notes et journal
## Résultat
/vlp:enchainer agents joue en même temps toutes les fiches lançables (2 d'office), chacune dans son worktree, et un mini-chantier à blanc le prouve, mesuré à la file puis en parallèle
## Notes
- ISO1 : un essai en worktree, ses réponses écrites sous le socle ; ne dépend de rien
- ISO2 : plus de fausse alerte « ailleurs » pour un worktree hérité ; ne dépend de rien
- ISO3 : lancables devient un indice, largeur 2 réglable ; après ISO1
- ISO4 : vlp.py fusionner, qui annule sur conflit ; après ISO1
- ISO5 : le texte d'état rendu au chef, vlp.py etat ; après ISO1
- ISO6 : le parallèle d'office dans /vlp:enchainer agents ; après ISO3, ISO4, ISO5
- ISO7 : le mini-chantier à blanc mesuré, à la file puis en parallèle ; après ISO6 et ISO2

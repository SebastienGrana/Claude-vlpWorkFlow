# Les garde-fous de fin de fiche — notes et journal
## Résultat
Une fiche corrige le test qu'elle a écrit, un ancien test reste figé ; le palier sauté de ROU2 est refait puis réparé ; aucun petit projet de test n'écrit plus l'état du vrai kit.
## Notes
- FIG1 : figer libère un test absent du dernier commit, ou un passage écrit pendant la fiche ; dépend de rien
- FIG2 : un test refait le palier sauté de ROU2, puis la réparation au centre (conftest) ; dépend de rien
- FIG3 : tous les petits projets de test au brouillon, seulement si FIG2 ne répare pas au centre ; dépend de FIG2
- FIG4 : valider avertit d'un test existant nommé sans ligne Tests ; dépend de FIG1

# Une republication ne joint que les joints changés — notes et journal
## Résultat
Une republication sans changement de vlp.css, vlp.js ou couts.svg ne les joint plus : plus de refus « joints non lus » dus aux fins de ligne.
## Notes
- JNT1 : Le nombre de refus « joints non lus » par publication, compté dans les transcriptions ; ne dépend de rien
- JNT2 : Les joints en LF dans tous les worktrees (.gitattributes) ; ne dépend de rien
- JNT3 : Le hook note l'empreinte des joints publiés, FILES ne nomme que ceux qui ont changé ; dépend de JNT2

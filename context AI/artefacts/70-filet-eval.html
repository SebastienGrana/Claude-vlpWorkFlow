Arrêt sur blocage

EVF1 : le fork vlp:jouer shelle systématiquement pour sa carte (un ! Bash) avant même de forker vlp:fiche — donc tout cas d'eval qui l'appelle exige un grant Bash, et ce grant exige un backend de sandbox absent nativement sous Windows. Ça touche EVF2 aussi, pas seulement EVF3 (déjà taggée wsl2).

exit 1: sandbox required but unavailable — sandbox is enabled but the Windows sandbox is not active on this session (feature gate off). sandbox.failIfUnavailable is set - refusing to start without a working sandbox.

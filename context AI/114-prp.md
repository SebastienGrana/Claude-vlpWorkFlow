## Le socle commun

Le découpage vient du plan du soir (`context AI/106-nuits.md`, section `### PRP`) : il a été
validé, il se suit tel quel.

**Le code de la découpe**, dans `scripts/vlp_coeur.py` — ligne du jour par
`vlp.py symboles scripts/vlp_coeur.py <nom>` :

| Symbole | Ce qu'il rend |
|---|---|
| `COMMIT_FICHE` | le motif d'un commit de fiche : `^([A-Z]{1,3}[0-9]+) :` |
| `heures_commits` | `(commits, prefixe, autres)` : 1er commit de chaque fiche ; heures des commits qui **nomment** le préfixe ; heures des autres |
| `plages` | `(plages des fiches, plages hors fiches)` ; aujourd'hui un commit `<PRÉFIXE> :` ne sert qu'à borner le début de la 1re fiche et la fin de la dernière |
| `plages_du_cout`, `parts_aux_commits`, `couts_aux_commits`, `couts` | la suite du calcul, jusqu'aux tables |
| `cmd_cout` | `vlp.py cout` : fiches, puis `hors fiches`, puis `TOTAL (fiches + hors fiches)` |
| `cmd_recompter` | `vlp.py recompter` : chaque ligne de `ZONE:clos` recomptée ; `--ecrire` écrit |
| `cmd_clore` | la clôture : seule à écrire la `ZONE:bilan` ; ligne `**Fait.**` (`ligne_fait`) |
| `recaler_texte`, `ecrire_abri`, `abri_de_page` | réécrire un `**Fait.**`, une page, l'abri `.md` |

**Les tests** : `scripts/test-vlp.py` — `tester_plages`, `tester_cout_session`,
`tester_cout_a_clore`, `tester_recompter_essais` sont les voisins à imiter. Un test bâtit son
projet dans un dossier temporaire, jamais le vrai dépôt. Le mutant se joue par `vlp.py mutant`
(forme dans la docstring de `scripts/vlp.py`) avec `--attendu "<début du libellé du test>"`.

**Les quatre copies du coût d'un clos** : la ligne `**Fait.**` du fichier de fiches, la
`ZONE:bilan` de sa page, l'abri `.md` de la page, sa ligne d'archive (`ZONE:clos`).

**Le journal** : `context AI/08-etat.md`, section « Journal des décisions » — une ligne datée
par décision.

**Invariants** :

- le **total** d'un chantier ne bouge pas : on déplace des tours d'une fiche vers « hors
  fiches », on n'en crée ni n'en perd ;
- aucun vrai clos n'est réécrit cette nuit : `--ecrire` ne se lance que dans un test ;
- `scripts/` reste sans dépendance ; `pyright` à zéro erreur sur les fichiers touchés.

**Hors du chantier** : recompter les vieux clos pour de vrai (un geste de jour, avec deux
oui) ; changer le prix (`TAU`) ; le coût des essais (`EFF`, chantier suivant).

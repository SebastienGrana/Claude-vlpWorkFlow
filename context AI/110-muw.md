| Symbole (`scripts/vlp_coeur.py`) | Ce qu'il fait aujourd'hui |
|---|---|
| `KIT` | dossier parent du script lancé — par le plugin, le dépôt principal (`main`) |
| `copie_mutee` | racine = `KIT` si la cible est sous `KIT`, sinon le dossier de la cible ; un worktree sous `.claude/worktrees/` passe pour « sous `KIT` » |
| `cmd_mutant` | tests = `os.path.join(KIT, "scripts", "test-vlp.py")`, passés par `vers_copie` |
| `est_kit` | vrai si un dossier porte `.claude-plugin/plugin.json` et `scripts/test-vlp.py` |
| `cmd_rapide` | racine = `--racine` ou le dossier courant, tests = `<racine>/scripts/test-vlp.py` — lu juste, à vérifier par l'essai |

les tests du kit qui contient la cible, et une ligne `TESTS <dossier>` nomme ce kit ; `rapide` est dedans ;
le défaut se **reproduit d'abord**.

Dehors : la doctrine (`methode-chantier.md` cite déjà `vlp.py mutant`, rien à y changer) ; un mutant hors du kit
garde son comportement actuel (le dossier de la cible).

## Le socle commun

Tout est dans `scripts/vlp_coeur.py` ; `vlp.py symboles scripts/vlp_coeur.py <nom>` rend la ligne du jour.

| Symbole | Ce qu'il fait |
|---|---|
| `rangee_todo(lignes, code)` | (en-tête `\| # \| Chantier`, rangée dont la 2e cellule commence par `` `code` ``, son numéro) ; `None` à leur place sinon |
| `cmd_oter` | ôte la rangée, ajoute à la phrase de provenance (dernière ligne non vide au-dessus de l'en-tête) ` <n>, `<code>`, retiré le <date> : <raison>.`, puis une entrée au journal ; `.tmp` + `os.replace` |
| `refus_de_clore` | lit la TODO par `todo_du_fichier` **avant** toute écriture (`TAB3`) : cassée, `GARDE: … — rien écrit` |
| `cmd_clore` | écrit fiches, index, page, `CHANTIER.md`, puis la feuille (« # 3. la feuille de route »), qui **relit** la TODO |
| `lettre_de(ids[0])` | le code du chantier dans `clore` — le préfixe des fiches, égal au code de la TODO depuis les trois majuscules |

la lisent (`lance_clore`, le matin) ; un code absent de la TODO (chantier hors TODO) n'est pas une erreur.

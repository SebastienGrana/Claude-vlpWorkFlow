**Les invariants de toutes les fiches.**

- Séparer : `assert a and b and c, msg` devient `assert a`, `assert b`, `assert c`, **sans message**, dans l'ordre ; un
  `and` imbriqué entre parenthèses se sépare aussi ; `assert not (a or b)` devient `assert not a`, `assert not b`.
  Chaque part garde son texte source (`ast.get_source_segment`), entre parenthèses si elle tient sur plusieurs lignes.
- Découper un long test : sous 50 instructions (`PLR0915`) et 10 de complexité (`C901`) ; la **première partie garde
  le nom d'origine** ; le décor partagé passe dans une fixture ou une fonction d'aide du même fichier ; aucune
  assertion ne se perd — `vlp.py retraits` (hook `commit-msg`, `scripts/retraits.py`) refuse une baisse des `assert`.
- Une fiche qui change un test existant porte `**Tests** : modifiés` (hook `figer`, `methode-chantier.md`, « Anatomie
  d'une fiche ») ; ces lignes sont celles du cadrage, validées par l'utilisateur.
- Un changement de forme est un **commit de rangement** à part d'un changement de comportement (REF15).
- Le cliquet de `scripts/sante.py` (`tenir_cliquet`) : une baisse ne le rompt pas ; `SEUIL_LIGNES` (1000 lignes)
  vaut pour `tests/` aussi — mesuré : séparer sans message porte les fichiers touchés de 13 130 à 14 077 lignes,
  aucun au-delà de 1000.
